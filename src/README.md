# Mehr VPN (Windows)

برنامه‌ی ویندوز برای اجرای هم‌زمان **OpenVPN اداره** و **v2ray** (با هسته‌ی sing-box).

- OpenVPN: `openvpn.exe` رسمی (OpenVPN Community) با کنترل از طریق management interface
- v2ray: sing-box در حالت TUN، با مسیریابی بر اساس نام برنامه (`process_name`)
- ترافیک خروجی sing-box به رابط شبکه‌ی OpenVPN bind می‌شود، پس سرور v2ray از داخل تونل اداره صدا زده می‌شود
- آدرس سرور OpenVPN از TUN مستثنی می‌شود تا قطع و وصل شدن OpenVPN دچار حلقه نشود

## حالت‌ها
1. **برنامه‌های انتخابی**: فقط برنامه‌هایی که انتخاب کردید از v2ray رد می‌شوند، بقیه‌ی سیستم فقط از OpenVPN
2. **همه‌ی برنامه‌ها** از v2ray رد شوند
3. **پراکسی سیستم**: بدون TUN، پراکسی محلی `127.0.0.1:2080` و تنظیم پراکسی ویندوز. برای عیب‌یابی

## بیلد
هر push به شاخه‌ی `main` یا اجرای دستی workflow، یک فایل `MehrVpn-win-x64.zip` در بخش Artifacts می‌سازد.
Workflow این‌ها را خودکار کنار برنامه می‌گذارد:

- `deps/singbox/sing-box.exe` (آخرین نسخه‌ی سری 1.12)
- `deps/singbox/wintun.dll`
- `deps/openvpn/openvpn.msi` (اگر دانلود شد)

## استفاده
1. zip را باز کنید و `MehrVpn.exe` را اجرا کنید (دسترسی Administrator لازم است).
2. تنظیمات: فایل `.ovpn` را انتخاب کنید (و اگر لازم بود نام کاربری و رمز). اگر OpenVPN نصب نیست «نصب OpenVPN» را بزنید.
3. سرورها: لینک vless / vmess / trojan / ss را اضافه کنید و یکی را انتخاب کنید.
4. برنامه‌ها: برنامه‌هایی که باید از v2ray رد شوند را اضافه کنید.
5. خانه: دکمه‌ی روشن/خاموش.

## امنیت
- پروفایل OpenVPN و لینک‌های سرور فقط روی همین سیستم در `%APPDATA%\MehrVpn` ذخیره می‌شوند
- رمز OpenVPN با DPAPI ویندوز رمزنگاری می‌شود و هنگام اتصال فقط چند ثانیه در فایل موقت است
- `.ovpn` و کانفیگ‌ها را داخل ریپو commit نکنید (`.gitignore` آن‌ها را نادیده می‌گیرد)

## اگر کار نکرد
صفحه‌ی «لاگ» را باز کنید، «اطلاعات شبکه» را بزنید و «کپی همه» را برای عیب‌یابی بفرستید.
